# Project 1: Rule-Based AI Chatbot

## 📋 Overview
A simple rule-based chatbot that responds to predefined user inputs using if-else logic. Built as the first project for the DecodeLabs AI Internship.

## ✨ Features
- Handles greetings (hello, hi, hey, hola)
- Handles exit commands (bye, exit, quit, goodbye)
- Responds to "how are you" and "what is your name"
- Runs in continuous loop until user exits
- Custom response for unknown inputs

## 🚀 How to Run
```bash
python chatbot.py
CHATBOT: Hello! I'm your AI assistant.
Type 'hello' to chat, or 'bye' to exit.

You: hello
Bot: Hey there! How can I help you today?

You: how are you
Bot: I'm great! Just processing logic all day. How about you?

You: bye
Bot: Goodbye! Thanks for chatting. See you next time! 😊

Chatbot session ended.
